# Plume Engine - Branding Assets

Ce dossier contient tous les éléments visuels de l'identité de Plume Engine.

## Structure

- **Logo/** - Logos du moteur en différents formats et variations
- **SplashScreen/** - Écrans de démarrage de l'éditeur
- **Icons/** - Icônes de l'application (Windows .ico, macOS .icns, Linux .png)

## Format

Tous les assets sont stockés en format SVG vectoriel pour garantir une qualité optimale à toutes les résolutions.

## Design

L'identité visuelle suit les principes définis dans la documentation :
- Minimalisme fonctionnel
- Hiérarchie visuelle claire
- Icônes vectorielles sharp et adaptables
- Cohérence avec les thèmes de l'éditeur
